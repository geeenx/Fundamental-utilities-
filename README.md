Week 5 Activities

Q1. Electricity Bill Calculator

A function named "calculateElectricBill()" calculates the total electricity bill based on the number of units consumed and the specified rates.

Billing rates:

- First 100 units: KSh 10 per unit
- Next 100 units: KSh 15 per unit
- Above 200 units: KSh 20 per unit

Q2. Fare Calculator

A function named "calculateFare()" calculates the total transportation fare based on the distance travelled.

Fare rate: KSh 50 per kilometre.

Q3. Temperature Converter

A function named "convertToCelsius()" converts temperature from Fahrenheit to Celsius using the formula:

[
C=(F-32)\times\frac{5}{9}
]

The purpose of these exercises is to understand how functions help organize programs into smaller, reusable blocks of code, making programs easier to read, maintain, and understand.
